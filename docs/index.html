01 / Overview & Architecture

Semantic gene blocks meet masked Optimal-Transport Flow Matching.

SAVE is a unified conditional generative framework for multi-condition single-cell RNA-seq modeling. Instead of attending over ~20,000 flat gene tokens, SAVE groups semantically related genes into balanced Gene Blocks and pairs a latent Variational Autoencoder with masked Optimal-Transport Flow Matching to model complex biological and technical covariates inside a single architecture.

01 / LLM KNOWLEDGE

LLM Biological Knowledge

Encodes curated NCBI Gene functional summaries via GenePT (1,536-dim semantic embeddings) and solves iterative Optimal Transport clustering to partition ~20,000 unordered genes into L balanced, pathway-coherent Gene Blocks (K = 3,200).

02 / LATENT FLOW MATCHING

Gene-Block VAE + DiT OT-FM

Compresses structured gene blocks (X ∈ ℝN×L×K) into pathway-structured latents (z ∈ ℝN×L×d), then trains DiT-based Conditional OT Flow Matching (AdaLN, condition masking p = 0.6, multi-condition CFG) across 1–5 covariates and 8 benchmarks with one fixed config.

03 / EFFICIENCY

191× Speedup & 20-Step Sampling

Grouping G ≈ 19,112 genes into L = 6 blocks collapses attention complexity from O(G2) to O(L2), cutting single-RTX-3090 training from 2,391.2 min (~40 h) to 12.5 min (266× / 9.0 min at K = 5,600; ~7 min on Colab G4).

LLM Semantic Gene Blocks vs. ViT Patchify

Standard Transformer models either attend over ~20,000 flat genes (O(G2) memory/time bottleneck) or lack a spatial 2D neighborhood for Vision Transformer (ViT) grid patching. SAVE replaces spatial proximity with LLM semantic similarity + balanced Optimal Transport soft-patching before feeding structured tokens into the Latent VAE + Latent Flow Matching stack.

  1. Stage 1 — LLM Semantic Embedding: Curated NCBI Gene text descriptions are encoded with a pre-trained LLM (text-embedding-ada-002, GenePT) into continuous 1,536-dim semantic vectors gi, injecting prior biological functional knowledge directly into tokenization.
  2. Stage 2 — Balanced Optimal Transport Soft-Patching → Latent FM: Iterative Optimal Transport minimizes squared Euclidean cost Cij = ‖gi − cj(t)‖22 under uniform marginal constraints (T1L = a, T⊤1G = b), yielding non-overlapping, equal-size functional blocks X ∈ ℝN×L×K that serve as compact tokens for Latent VAE + OT Flow Matching.
Dimension ViT Patchify (Vision Domain) SAVE Gene Block Mechanism (Genomics Domain)
Input Data Structure Structured 2D pixel grid Unordered, high-dimensional & sparse gene set (~20,000 genes)
Grouping Basis Physical proximity (Euclidean grid) Biological semantic similarity (pre-trained LLM prior on NCBI descriptions)
Patching Type Hard-patching (fixed spatial grid) Semantic soft-patching (iterative balanced Optimal Transport clustering)
Token Properties Functionally agnostic image patches Functionally coupled pathway blocks (coherent gene programs)
Downstream Stack & Efficiency Flat patch ViT attention Latent VAE + Latent OT Flow Matching (O(L2) attention, 191× training speedup: 12.5 min vs. 2,391.2 min on RTX 3090)

03 / Biological Interpretability

Condition-modulated attention recovers coherent biological pathways.

Extracting condition-modulated attention weights from the Flow Matching Transformer on Heart (16,000 HVGs partitioned into 5 blocks of size 3,200) shows that SAVE attends to biologically meaningful gene programs across cell types and batches.

Physiological Alignment

Atrial and ventricular cardiomyocytes consistently attend to Block 1 (Fatty Acid β-Oxidation), matching the heart's primary lipid metabolism signature across batches.

Functional Specificity

Endothelial cells and fibroblasts dynamically shift attention toward Block 4 (Adenylate Cyclase-Activating GPCR Signaling) and Block 3 (Protein Localization to Plasma Membrane), reflecting extracellular signaling and structural roles.

Biological Filtering

Block 2 (Broad/General Cellular Functions without a dominant enriched pathway) is universally suppressed across conditions, demonstrating autonomous filtering of non-discriminative gene programs.
